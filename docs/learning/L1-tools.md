# L1：工具边界与安全

工具不是“让模型直接执行任意代码”的后门，而是带有明确输入、输出和安全边界的能力。

本阶段实现了三个基础概念：

- `PathPolicy`：所有文件访问先解析真实路径，拒绝 workspace 外部路径以及 `.git`、`.loom` 元数据。
- `read_file`：按行读取，给模型有限预览；完整结果保存在本地 raw 文件中，必要时通过 `rawRef` 展开。
- `search`：通过参数数组调用 `rg`，不使用 shell 拼接；无匹配是成功结果，不把“没有结果”误判为工具故障。

`DefaultToolRegistry` 是模型工具调用和真实实现之间的边界：它负责查找工具、校验参数、统一返回结构。模型只能调用注册过的 schema，不能绕过注册表访问内部函数。

学习重点：工具结果既是模型输入，也是执行审计的一部分。因此结果需要稳定、可截断、可追溯，而不是把原始 stdout 无限制塞回上下文。
